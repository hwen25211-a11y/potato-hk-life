# v0.1.3 · 阿晴的周末与城市明信片

2026-10-24 玩法更新，2026-10-26 统一版本并重新构建。主分支源码、游戏内显示、Mac 与浏览器包统一为 **0.1.3**，并替换原发布入口的试玩包。旧存档可继续使用，升级前请关闭旧游戏和启动器。

## 本轮迭代

- **阿晴的周末邀请**：新增大澳散步、校园吃饭、独处半日三种安排，包含行囊故事、途中消息、回信和可回看的故事纪念。
- **城市明信片**：新增 12 张真实香港照片，支持拆开、翻看背面和查看大图；重复经过会留下记录。
- **港硕必备小店**：新增转换插头、电饭煲、抽湿机等生活用品，以及交通储值卡和电话卡。
- **旅行相框**：可摆放和拖动，选择已拆开的城市明信片装进相框，各房间分别保存位置。
- **毕业手账**：根据实际游玩记录回顾方向、照片、朋友来信、学习时间和故事纪念。
- **更快试玩**：演示模式每次外出由 30 秒缩短至 5 秒；慢生活模式保持 30—120 分钟。

此前的陪伴学习、每日任务、个人待办、五间房子、家具拖动和窗口失焦暂停音乐继续保留。完整细节见 [CHANGELOG.md](../CHANGELOG.md)。

## 下载与运行

- **Mac**：下载 `PotatoHK-Mac-v0.1.3.zip`，完整解压后打开「土豆子的港硕生活.app」。首次如被系统拦截，在「系统设置 → 隐私与安全性」选择「仍要打开」。游戏内版本为 v0.1.3。
- **Windows / 浏览器**：下载 `PotatoHK-Browser-v0.1.3.zip`，安装 Python 3，双击对应系统启动器，访问 `http://127.0.0.1:8918`，保持启动器窗口打开。
- **开发者**：主分支包含 Unity 工程源码，使用 Unity 2022.3.62f3c1 打开。Release 的源码归档对应本次更新，不含构建缓存或安装包。
